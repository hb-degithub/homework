# Homework - 前端训练营每日作业（学习项目）

## 项目简介

本仓库用于存放前端训练营的每日学习作业，记录从基础 HTML/CSS 到现代前端框架的完整学习过程。

> **注意：本项目为学习项目，仅用于学习交流。**

## 技术栈及说明

| 阶段 | 技术 | 说明 |
|------|------|------|
| DAY01 | HTML + CSS | 单文件个人作品集，内联样式 |
| DAY02 | Markdown | Git 学习笔记 |
| DAY03 | HTML + CSS + JS | 三文件分离，代码模块化 |

## 目录结构及说明

```
homework/
├── day01/                  # DAY01 - 单文件作品集
│   └── portfolio.html      # 个人作品集（HTML+CSS 内联）
├── day02/                  # DAY02 - Git 学习笔记
│   └── git-notes.md        # Git 版本控制学习笔记
├── day03/                  # DAY03 - 代码拆分
│   ├── index.html          # 页面结构
│   ├── style.css           # 样式文件
│   └── script.js           # 脚本文件
└── README.md               # 项目说明
```

## 每日内容

### DAY01 - 个人作品集（单文件）
- 使用纯 HTML + 内联 CSS 创建个人作品集页面
- 包含：姓名简介、技能列表、作品展示、联系方式
- 深蓝色主题，简洁现代风格

### DAY02 - Git 学习笔记
- Git 版本控制系统学习
- 常用命令：init、add、commit、push、pull
- 分支管理与远程仓库操作

### DAY03 - 代码拆分
- 将 DAY01 的单文件拆分为三个独立文件
- HTML 结构、CSS 样式、JavaScript 交互分离
- 添加动画效果和悬停交互
